1. Lead with a protection status table that answers "is the bed check actually working right now?" per printer, instead of making you infer it from a reading. 2. Turn the seven-control row into four named safety layers, each one line: what it does, its value, and whether it's currently doing anything. 3. Per-printer cards lead with the reading as a headline number; the four images collapse behind a disclosure, since they're for diagnosis, not monitoring.

The Meaning column is the point. A bare "5.57" reads like a pass because it's under 6.0 — but an empty bed on a good reference reads ~0.2, so anything mid-range means the reference has stopped describing an empty bed. That distinction is what the page never made, and it's why a mid-range number looked fine.

Safety layers what stands between a pooled job and a print starting

Pixel backstop
Compares the live frame with the saved empty-bed reference. Catches a dark part on a dark plate, which vision models routinely miss.
limit
Block when the reading can't be trusted off — waiting on bed-height fix
Treats a mid-range reading as "cannot tell" rather than a pass. Would have stopped the 2026-08-01 print. Turning it on today blocks all five printers until references are recaptured.
above 3.0
Confirm with a second look
A "clear" verdict must survive a second, freshly captured snapshot. Only runs when the first look approves, so a dirty bed costs nothing.
2 passes
Hold after a print finishes
The bed is certainly occupied straight after a print, so no check runs during this window. Deterministic — doesn't rely on the camera at all.
min
Self-refresh the reference
Adopts a passing frame as the new baseline, but only at or below 3.0 — so it keeps a good reference current and cannot rescue a stale one. Capture the first one by hand.
≤ 3.0 adopts
Replaces the seven-control wrapping row. Each layer states what it protects against and whether it's currently doing anything — the amber flag on layer 2 is a deliberate reminder that a written, tested safety layer is switched off on purpose, which a bare unchecked box would never convey.
